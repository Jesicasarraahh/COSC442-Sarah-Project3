# AI-Generated Tests Review
The overall quality of the generated tests were okay, if I had to rate it out of 10 I would probably give it a 7. The test method names Claude created were too lengthy, I do not think method names needed to be that long, and in my opinion it made the test suite feel too wordy and harder to easily scan through methods. However, the AI provided really good detailed Javadocs for every test method which I did not really do, the javadoc comments helped to understand what to expect from the test methods. If I have to compare the Claude generated tests to my own, I think the coverage was fine for both, both had 100% coverage for VendingMachine.java and VendingMachineItem.java. However, test quality could have been a little better for Claude, in the beginning it provided me with around 160 tests from which 1 of them failed so only 159 of them passed. Then, in order to edit the tests with coverage Claude added 13 more tests and after that we now had 173 total tests, from which 171 passed and 2 failed. I also do think some of the tests felt too complicated, for example testInsertMoney_notANumber_throwsException() and understanding Double.NaN. 

Additionally, I would say coverage guided prompting did improve the suite a little bit; although we already had 100% coverage for both the files. It improved the different kind of behaviors that should be checked, and I think I had not done that in my manual tests. Such as it tested by inserting  $0.10 ten times and trying to buy an item that is $1.0 but that failed because of the exact floating rounding done and it did not quite reach $1.0 and stopped at $0.999999999… .So that kind of helped me understand something new, and a fault I had not known before. Additionally, Claude did generate code that was a little redundant for example there were different tests that repeated the purchase boundaries that were already included in the parameterized tests. I learned that AI/LLMs can easily generate codes in a few minutes however not always will they be readable, some of them could be too complicated and lenghthy, which means the tests still need some type of human review.
